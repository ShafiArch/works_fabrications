# Fabrication Works

Shafiul Islam's fabrication projects on one page: https://shafiarch.github.io/works_fabrications/

1. **Sentience**, your personal money agent (Arduino, 3D printing)
2. **Parametric Screening** for a window aperture (CNC milling, laser cutting)
3. **Sketchbook Corner Piece** (3D printing)

The folders `Sentience/`, `parametric_screen/` and `book_corner_pcs/` hold the original exports. The page (`index.html`, `assets/`) uses web copies in `img/` (WebP, transparency kept). To change a text, edit `index.html`; to swap an image, export a new WebP into `img/<project>/` with the same name.

Writing rule: no em dashes or en dashes; commas, semicolons, parentheses or periods.
